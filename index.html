سياسة الخصوصية لتطبيق مؤسسة العطاء الخيرية

آخر تحديث: 9 يونيو 2026

تلتزم مؤسسة العطاء الخيرية ("نحن" أو "المؤسسة") بحماية خصوصية بيانات المستخدمين والمستفيدين. توضح سياسة الخصوصية هذه كيفية جمع واستخدام وحماية المعلومات الشخصية داخل تطبيق إدارة المؤسسة.

1. المعلومات التي نجمعها

نظراً لطبيعة عمل التطبيق في إدارة المساعدات الخيرية، نقوم بجمع البيانات التالية:

1.1 بيانات المستخدمين (الباحثين والموظفين)

  • الاسم، البريد الإلكتروني، ورقم الهاتف (للمصادقة وإدارة الصلاحيات).
  • على الجهاز فقط: قد يُخزَّن آخر اسم مستخدم ناجح في تخزين آمن (Secure Storage) لتعبئة حقل تسجيل الدخول؛ لا يُرسل إلى أطراف ثالثة.

1.2 بيانات المستفيدين

  • الاسم الرباعي، الرقم القومي، رقم الهاتف، العنوان، المحافظة
  • الحالة الاجتماعية، بيانات السكن (إيجار، ملكية، إلخ)
  • الدخل المالي والعائلي، المصروفات، الديون، المساعدات السابقة
  • قصة الحالة، الملاحظات النصية أو الصوتية المُحوّلة إلى نص
  • عدد الأطفال وأعمارهم، بيانات الزوج/الزوجة عند الاقتضاء

1.3 بيانات تقنية (لتحسين الأداء واكتشاف الأخطاء)

نستخدم خدمة Sentry لمراقبة أعطال التطبيق وأدائه. قد تُرسَل تلقائياً معلومات تقنية تشمل: نوع الجهاز، نظام التشغيل، إصدار التطبيق، رسائل خطأ وتتبع مكدس (Stack Trace)، ومقاييس أداء مجمعة. لا نرسل أسماء المستفيدين أو أي بيانات شخصية حساسة إلى Sentry. لمزيد من التفاصيل: سياسة خصوصية Sentry.

1.4 الإشعارات الفورية (Push) ورمز الجهاز

  • للموظفين والمستخدمين المخوّلين الذين يسجّلون الدخول ويوافقون على استقبال الإشعارات: نخزّن على خوادمنا (Supabase) رمز إشعار الجهاز (FCM token) مرتبطاً بمعرّف حساب المستخدم في النظام، لتمكين إرسال تنبيهات عند أحداث تتطلب المتابعة (مثل سجلات العمليات أو تسجيل حالة جديدة). يُزال هذا الارتباط من الخادم عند تسجيل الخروج حيثما ينطبق ذلك في التطبيق.
  • لتسليم الإشعار نستخدم Firebase Cloud Messaging (FCM) التابع لـ Google. قد يتضمن نص الإشعار المعروض على الجهاز معلوماتاً تشغيلية مستخرجة من سجلات النظام (نوع الحدث ووصف مختصر). في بعض الحالات (مثل تنبيه «حالة جديدة») قد يظهر في النص معرّفات محدودة تتعلق بالحالة كالاسم الرباعي ورقم الملف واسم المستخدم المُنشئ، وذلك فقط لعرض التنبيه على أجهزة الموظفين المصرّح لهم — لا لأغراض تسويقية وليس عبر Sentry.

1.5 نشاط الموظفين والحضور (للموظفين فقط)

  • للموظفين والمستخدمين الإداريين المخوّلين فقط: نسجّل على خوادمنا (Supabase) وقت آخر دخول للتطبيق ووقت آخر نشاط أثناء بقاء التطبيق مفتوحاً (نبضات دورية محدودة لتحديث الحضور؛ وليس تتبعاً للموقع الجغرافي).
  • تُستخدم هذه البيانات لأغراض إشرافية داخل المؤسسة ويمكن لمدير النظام الأعلى الاطلاع عليها؛ لا تُباع ولا تُستخدم لأغراض تسويقية.

2. كيف نستخدم هذه المعلومات؟

نستخدم هذه البيانات حصرياً للأغراض التالية:

  • تقييم طلبات المساعدة والتقصي الميداني
  • ضمان التوزيع العادل للمساعدات (زكاة، لحوم، كفالات) ومنع الازدواجية
  • التواصل مع المستفيدين لتسليم المساعدات
  • استخراج تقارير وكشوف صرف داخلية ومؤمنة بصيغة PDF
  • تشغيل التطبيق وتحسينه واكتشاف الأعطال عبر Sentry
  • إعلام الموظفين المصرّح لهم بأحداث تتطلب المتابعة عبر إشعارات فورية (Push) وعرض الإشعارات داخل التطبيق عبر تحديثات فورية (Supabase Realtime)
  • متابعة اتصال الموظفين ونشاطهم التشغيلي لأغراض إدارية ودعم داخلي (للاطلاع من مدير النظام الأعلى فقط)

3. حماية البيانات والأمان

نحن نأخذ أمان بياناتكم على محمل الجد:

  • نستخدم Supabase كمنصة تخزين سحابية تتمتع بسياسات أمان صفية (Row Level Security - RLS)، حيث لا يستطيع أي باحث الاطلاع إلا على الحالات المخصصة له.
  • جميع البيانات تُنقَل عبر قنوات مشفرة (HTTPS).
  • نُخزّن جلسات تسجيل الدخول في وحدة تخزين آمنة على الجهاز (Secure Storage).
  • عند بقاء التطبيق في الخلفية لفترة قصيرة، يُقفل المحتوى حتى إعادة التحقق عبر بصمة الإصبع / Face ID أو كلمة مرور الحساب. يتم التحقق البيومتري محلياً على الجهاز ولا نخزّن بيانات البصمة أو الوجه على خوادمنا.
  • نستخدم أدوات أمان (مثل freeRASP) للكشف عن التلاعب بالتطبيق أو تشغيله على أجهزة مُعدّلة (Root/Jailbreak)؛ عند اكتشاف تهديد، يتم تسجيل خروج المستخدم تلقائياً لحماية البيانات.

4. مشاركة البيانات مع أطراف ثالثة

4.1 عدم البيع أو التأجير

نحن لا نبيع ولا نؤجر ولا نشارك بيانات المستفيدين أو المستخدمين مع أي جهات خارجية لأغراض تسويقية.

4.2 مقدّمو الخدمات التقنية

تُخزَّن البيانات على خوادم Supabase وتتوافق مع معايير الأمان الدولية (GDPR وغيرها).

تُرسَل بيانات تقنية مجمعة (أعطال، أداء) إلى Sentry لمساعدتنا في إصلاح الأخطاء وتحسين التطبيق. لا نرسل هويات المستفيدين أو بياناتهم الشخصية إلى Sentry.

قد يتم تحميل خطوط من Google Fonts لعرض النصوص وتوليد ملفات PDF داخل التطبيق.

لتسليم الإشعارات الفورية نستخدم Firebase Cloud Messaging (FCM) عبر Google؛ تمر رسائل الإشعار (بما في ذلك العنوان والنص الظاهر على الجهاز) عبر بنية Google لتوصيلها إلى تطبيقك. لا يُستخدم ذلك لبيع البيانات أو الإعلانات التسويقية. لمزيد من التفاصيل: خصوصية وشروط Firebase.

4.3 روابط خارجية

يتضمن التطبيق إمكانية فتح تطبيق واتساب للتواصل مع المؤسسة؛ في هذه الحالة تخضع معالجة البيانات لسياسة خصوصية واتساب وليس لسياستنا.

5. صلاحيات الجهاز المطلوبة

لضمان عمل التطبيق بكفاءة، قد يطلب التطبيق الوصول إلى:

الصلاحية الغرض
الميكروفون تفعيل خاصية تحويل الصوت إلى نص (Speech-to-Text) لتسهيل إدخال الباحثين لقصة الحالة والملاحظات الطويلة. لا نقوم بتسجيل أو حفظ الملفات الصوتية؛ الصوت يُحوَّل فوراً إلى نص ولا يُخزَّن في أي خادم.
الإنترنت مزامنة البيانات مع السحابة (Supabase)، تحميل الخطوط، إرسال تقارير الأعطال (Sentry)، وتسجيل أو تحديث رمز الإشعارات (FCM) على الخادم عند تسجيل الدخول.
الإشعارات (Android 13+) صلاحية عرض الإشعارات (POST_NOTIFICATIONS) لإظهار تنبيهات Firebase Cloud Messaging على شاشة الجهاز. على iOS يطلب النظام السماح بالتنبيهات عبر مربع الحوار المعتاد.
البصمة / Face ID إعادة فتح التطبيق بعد الخروج من الخلفية لحماية بيانات المستفيدين؛ التحقق يتم محلياً على الجهاز ولا يُرسل إلى خوادمنا.
المشاركة / الطباعة لتصدير كشوف التوزيع وقوائم المستفيدين بصيغة PDF ومشاركتها أو طباعتها عبر واجهة الجهاز. المستخدم يختار أين يُحفظ الملف أو مع من يُشارك.

6. حقوق المستخدم

  • يحق لمديري النظام (Admins) تعديل أو حذف بيانات المستفيدين عند انتهاء الحاجة إليها أو بناءً على طلب المستفيد، عبر الواجهة المخصصة في التطبيق.
  • يمكن للمستخدمين طلب الاطلاع أو التصحيح أو الحذف لبياناتهم الشخصية عبر التواصل معنا.

7. مدة الاحتفاظ بالبيانات

نحتفظ بالبيانات طوال مدة الحاجة إليها لتنفيذ أهداف المؤسسة الخيرية. في حال انتهاء العلاقة أو طلب الحذف، نعمل على حذف أو إخفاء البيانات وفق سياساتنا الداخلية والقانون المعمول به.
